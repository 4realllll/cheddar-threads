# Позы Чеддера для картинок

Вырезаны из исходников (`assets/poses-src/`) с белой обводкой-стикером, фон прозрачный.

| Файл | Поза | Под какое настроение |
|---|---|---|
| `thinking.png` | думает, «?» | вопрос к аудитории, дилемма, «как бы вы поступили» |
| `shocked.png` | в шоке, лапки к щекам | неожиданная ситуация, «ну и ну» |
| `laughing.png` | смеётся | смешная сценка, самоирония |
| `pointing.png` | показывает лапкой | совет, «смотрите», полезное |
| `waving.png` | машет | приветствие, начало недели, «доброе утро» |
| `hiding-behind-tablet.png` | прячется за планшетом, пот | неловкость, страшное (конец месяца, родительский чат) |
| `detective-magnifier.png` | детектив с лупой | разобраться, «расследование», загадка |
| `detective-tablet.png` | детектив за планшетом | проверка, подсчёты, «всё сошлось» |
| `confetti.png` | радуется с конфетти | успех, праздник, «ученик понял тему» |
| `avatar-circle.png` | аватарка в круге | запасной вариант |

«Спит на сыре» не вырезана: на жёлтом фоне сыр сливается (исходник лежит в `poses-src/`).
