# Что умеет бот (для постов) — копия из проекта «Chedder», 14.11.2026

Источник правды — документ проекта `claude/chedder-функции.md`. Не обещаем ничего, чего здесь нет.

- Где: мессенджер **MAX** — бот + мини-приложение (календарь недели, светлая/тёмная тема). Сервер в России. Цену не называем.
- Вход по приглашению; роли: владелец, администратор, преподаватель, родитель.

## Сильные темы
1. **Остаток считается сам**: 🟢 3+ / 🟡 1–2 / 🔴 0, «остался 1 урок» с кнопкой оплаты.
2. **Продление в один тап**: родитель видит кнопку «Продлить», преподаватель выставляет счёт или подтверждает оплату. Деньги идут вне бота, подтверждает человек.
3. **Родители в курсе сами**: каждое проведённое занятие с остатком, отмены и переносы, предупреждение о конце абонемента (порог 1–5 выбирает родитель).
4. **Переезд из таблицы за минуту**: загрузка учеников из Excel/CSV, выгрузка обратно в Excel.
5. **Напоминание перед уроком** с записями прошлого занятия: тема, успехи, ДЗ.
6. **Забытые отметки**: экран «Без отметки», отметка задним числом.
7. **Общий абонемент** на братьев и сестёр (один остаток, расписание у каждого своё).
8. **Итоги недели и месяца** для преподавателя.
9. **Для школ**: роли, сводная статистика у администратора, вход по приглашению.
10. **Надёжность**: ежедневные зашифрованные резервные копии.

## Расписание
Регулярные правила (день, время, длительность, место), предупреждение о пересечениях; экраны Сегодня / Неделя / Без отметки; отметки Проведено / Отмена / Перенос.

## Нет и не обещаем
Самозапись и перенос учеником без переписки, публичная страница преподавателя, расчёт зарплаты, Telegram-версия, переписка с родителем из карточки продления.
